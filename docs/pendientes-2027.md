# Pendientes para las bases 2027

## Retiros por lesión durante un partido

### Antecedente de 2026

Las bases 2026 no definieron cuántos puntos correspondían cuando un jugador se retiraba por lesión después de comenzar el partido.

En el partido entre Cristhian Linares y Diego Cervantes, Diego había ganado el primer set y se retiró por lesión durante el segundo. Cristhian ofreció mantener un reparto de 2–1 y la administración aceptó ese criterio para la temporada 2026.

Este antecedente es una solución excepcional de 2026 y no debe convertirse automáticamente en la regla de 2027.

### Regla definida para la temporada 2027

- Un retiro antes de comenzar el primer punto se considera W/O.
- Una vez comenzado el partido, se conserva el marcador efectivamente disputado.
- Todos los games que falten para completar el partido se adjudican al jugador que no se retiró, como si los hubiese ganado sin perder puntos.
- Si el retirado ganó un set regular, el reparto es `2-1` en puntos. Se completa el set en curso para el ganador y el super tie-break pendiente se registra `10-0`.
- Si el retirado no ganó ningún set regular, el reparto es `3-0` y se completan los sets restantes para el ganador.
- Si el retiro ocurre durante el super tie-break, se conserva el marcador alcanzado y el ganador recibe los puntos restantes hasta completar un super tie-break válido.
- El super tie-break decide el partido, pero no cuenta como set ni como game.
- El administrador debe ofrecer `Retiro` como resultado propio y aplicar automáticamente esta regla.
- La regla debe incorporarse a las bases públicas antes de comenzar el torneo.

Estado: criterio deportivo definido; falta implementarlo en el administrador y publicarlo en las bases.
